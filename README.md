# About

InvestmentBuddy is a stocks investment application designed for beginner investors. When users create an investment portfolio, they can add or remove as many investments as desired. Portfolio performance can be visually displayed via interactive graphs, or by generating robust dashboard insights. Example use cases that InvestmentBuddy addresses are:

1) If I have *x* amount of dollars, what are the best stocks to invest in?
2) What is my current balance and performance activity?

InvestmentBuddy offers users who are not familiar with investing a user-friendly UI, which includes easy navigation through guidance and helpful tips. It pulls market data through a trusted API, so users always have up-to-date information when evaluating their portfolios.

This application was a result of a collaborative semester-long group project at CSUSM involving three other team members.

# Instructions to Run the Application

To run the application, simply ensure that Java (JRE 17 or higher) is installed on your local machine. No additional software, database, or external setup is required. Download or extract the project folder, which contains the .jar file and a data/ folder. Then, double-click the .jar file to launch the application, or run it via terminal ‘with java -jar InvestmentBuddy.jar.’ All data is saved locally in plain .csv and .json files inside the data/ directory, making the system fully self-contained and portable.
